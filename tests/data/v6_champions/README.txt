바이트까지 같다. 테스트는 읽기만 하고 여기는 고치지 않는다. tests/test_oracle_sane.py(T0)가 지금 환경 배치와 맞는지 본다.

npz 키: genome(float64, layout_for(spec).dim), env_file, env_sha256(고를 때 environments/ 파일의 sha256), layout_signature
(그 실행 run.json의 값 = 지금 layout_for(spec).signature()), generation(챔피언 세대), run_seed, score(그 실행이 잰 챔피언 검증
점수), source(실행 폴더 이름과 만든 설정). 유전자는 원래 챔피언 파일의 genome
그대로(바이트 같음)이고 나머지 키는 이 폴더를 만들 때 붙였다. 만든 기계: 리눅스 x86_64, python 3.12.3, numpy 2.5.4, pymunk 7.3.1.
