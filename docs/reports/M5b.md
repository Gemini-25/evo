# M5b 보고: 에디터 2부 (모터, 언덕)

## 바뀐 것

- **모터 구동기**(런타임): 회전 관절(pivot, rot_spring)에 Chipmunk SimpleMotor. 출력 u면 b 물체가 a에 대해
  u × max_speed(rad/s, +는 반시계)로 돌도록 최대 max_torque까지. 검사: 회전 관절이 아니거나 에이전트의 움직이는 물체에
  안 붙은 관절이면 오류. 직접 조종 키(keys_pos +1 / keys_neg −1).
- **언덕 생성기**(hills): 평지 뒤 오르막(slope) + 거리에 따라 커지는 굴곡(amplitude + growth × 거리), 지형 생성기와 같은
  시드 규칙(비트 동일). 물체 id는 생성기 id, 태그 terrain.
- **hill_car.evoenv**(먼저 손으로 씀): 차체(다각형, 꼭짓점 높이 진화), 바퀴 2개(반지름 진화), 회전 관절 + 모터 2개
  (토크 300, 15rad/s), 센서 11개(차체 상태 4, 앞쪽 땅 레이 5, 바퀴 접지 2), 점수: 전진 거리 +1/m, 끝까지 +100, 뒤집힘 −20,
  에너지 −0.05. 몸 유전자 5개 + 뇌 226 = 231차원.
- **에디터 도구**: 모터(회전 관절 클릭), 언덕 자동 생성.

## 학습 확인 (명세: 먼저 손으로 쓴 hill_car.evoenv가 학습되는지)

리눅스 4코어, 다른 학습과 함께 돌아 워커 1개, 시험 2만 회 예산(실행 시드 1):

| | 몸 수치(차체 반길이, 앞 높이, 뒤 높이, 뒷바퀴, 앞바퀴) | 전진 거리(검증) |
| --- | --- | --- |
| 처음 몸으로 끝까지 밟기(학습 없음) | 1.1, 0.35, 0.35, 0.5, 0.5 | 190.5m (같은 검증 시드 20개 평균) |
| 11세대 챔피언 | 1.785, 0.263, 0.171, 0.936, 0.885 | 238.9m |
| 115세대 챔피언 | 1.707, 0.112, 0.112, 0.963, 1.000 | **249.2m** (+31%) |

바퀴가 커지고 차체가 길어지는 쪽으로 몸이 진화했다(토크 300에서 큰 바퀴가 빠르지만, 끝까지 밟으면 앞이 들려 뒤집히는 경우가
있어 조종도 같이 배운다). 에디터로 다시 만든 hill_car는 내장 예제와 내용 해시가 같다(M5a 보고서 표) → 같은 학습.

## 직접 확인할 항목

1. 실험실에서 '언덕 넘는 자동차'를 고르고 학습 → 관전 화면에서 바퀴가 커지는지(몸 진화)
2. 직접 조종: ←/A, →/D로 바퀴를 돌려 언덕 넘기
3. 에디터에서 '언덕 자동 생성', 관절을 고르고 '모터' 도구로 모터 달기
