# v3.1 보고: 나누기와 설치 (설치 프로그램, MP4, 폰 재생 파일)

## 요약

- **무엇**: v3 「쓰기 편하게」의 두 번째 출시입니다(명세 부록 A65, A80~A90). 만든 프로그램을 다른 사람에게 건네고(설치 프로그램, 휴대용
  zip, 체크섬, 릴리스), 학습 결과를 밖으로 가져가게(MP4, 폰 재생 파일, 명령줄 내보내기) 했습니다. 환경 파일, 실행 폴더, 재현 묶음, 워커
  메시지, 학습 계산은 바꾸지 않았고 새 실행 의존성도 없습니다(`uv.lock` 차이는 evolab 버전 줄뿐). 버전은 3.1.0이고 커밋은 a96e3bd입니다.
  - **설치 프로그램**: Inno Setup 6, 사용자별 설치(`%LOCALAPPDATA%\Programs\진화 실험실`, 관리자 권한 없음), 시작 메뉴 두 개(프로그램, 오류 보고
    묶음 만들기)·바탕 화면 바로 가기(기본 켬), 고정 AppId로 덮어 설치, 내려 설치 확인(기본 아니요), 실행 중이면 닫으라고 함, 제거해도 실험 기록은
    남김(설정·로그는 물어봄). `.evoenv` 파일 연결은 설계대로 미뤘습니다(설계 Q7).
  - **배포 파일**: 설치 파일 `evolab-setup-3.1.0.exe`, 휴대용 `evolab-3.1.0-portable.zip`(안에 「설치 없이 쓰기.txt」), `SHA256SUMS.txt`, 태그
    `v*`에서 도는 `release` job, 두 exe의 파일 버전 3.1.0.0. 코드 서명은 인증서가 없어 방법 문서(`docs/signing.md`)와 서명 없는 PE 목록 도구만
    두었습니다.
  - **내보내기**: 실험실·나란히 경주 창의 「내보내기…」 대화 상자 하나(MP4·GIF·폰 재생 파일, 크기, 고정·따라가기 카메라). 그리기와 쓰기는
    spawn 자식 프로세스가 하고(진행·취소·갑자기 끝남을 화면이 받음), MP4는 윈도우 Media Foundation H.264가 되면 그것, 안 되면 numpy로 쓴 내장
    무손실 H.264 쓰기입니다. 폰 재생 파일은 인터넷 없이 폰 브라우저에서 열리는 HTML 하나입니다. `evolab export`·`evolab video-probe`, 자체 점검
    「내보내기」를 더했습니다.
  - **v3.0에서 넘어온 것**: 기록·나란히 경주·비교 화면의 자체 오류 도우미 8곳을 `errors.show_error`·`errors.reason`으로 바꿨고(자리 수 0),
    에디터 팔레트 격자 간격 칸에 풍선 도움말을 붙였습니다.
- **완료 기준**: 아래 「완료 기준 점검」 표(설계 9.3 v3.1 기준 7개)에 있습니다.
