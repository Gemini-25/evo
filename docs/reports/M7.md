# M7 보고: 배포 마무리

## 바뀐 것

- 첫 실행 때 내장 예제(착륙선, 트랙 자동차, 언덕차)를 `문서\진화실험실\environments`로 복사(이미 있는 파일은 그대로).
- 아이콘: exe 두 개와 창(`packaging/icons/evolab.ico`, `src/evolab/assets/icon.png`).
- 라이선스 고지: 빌드 때 의존성 라이선스 파일과 요약(`licenses/THIRD_PARTY_NOTICES.txt`)을 배포본에 넣음. Qt(PySide6)는
  LGPLv3 전문 동봉(동적 링크, Qt DLL은 사용자가 바꿀 수 있음). '도움말 → 정보…'에서 보이고 라이선스 폴더를 열 수 있음.
- '도움말 → 데이터 폴더 열기'.
- 자체 점검에 '내장 예제와 배포 파일'(예제 3개 컴파일, exe면 아이콘·라이선스 고지 확인).
- CI: 묶은 exe를 한글 경로에서 실행해 착륙선 학습(3세대) → 판정 → 재현 묶음 → 다시 돌려 통계 비교까지(종료 코드 0이어야 통과).

## 완료 기준

"파이썬이 없는 윈도우 PC에서 exe를 더블클릭해 착륙선 학습까지 된다."

- 배포본은 PyInstaller 한 폴더(onedir)라 파이썬 설치가 필요 없다(파이썬 런타임 포함). CI는 GitHub 윈도우 러너에서 묶은 exe를
  한글 경로로 복사해 `evolab-cli.exe`로 학습·판정·재현을 돌리고, 창 모드 `evolab.exe selftest`(창, 학습 프로세스 → 워커
  중첩 spawn 포함)도 돌린다. 결과는 최종 보고서의 CI 표.
- CI 러너에는 파이썬이 깔려 있지만 exe는 그것을 쓰지 않는다(배포본 안의 python312.dll). 파이썬이 정말 없는 PC에서의 더블클릭은
  사용자 PC에서 확인할 항목으로 남긴다.

## 직접 확인할 항목

1. Actions의 `evolab-windows`를 내려받아 파이썬이 없는 PC(또는 다른 폴더)에 풀고 `evolab.exe` 더블클릭
2. 실험실 → 달 착륙선 → 새로 시작 → 몇 세대 학습되는지, 창을 닫았다 열어 기록 탭에서 이어하기
3. '도움말 → 정보…'에서 라이선스 고지가 보이는지
4. `문서\진화실험실\environments`에 예제 3개가 복사됐는지
