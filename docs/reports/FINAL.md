# 최종 보고 (1차 M0~M7)

사용자가 자리를 비운 동안(2026-11-06~07) "최종까지 알아서 진행"을 맡겨 M2부터 M7까지 멈추지 않고 진행했습니다. 마일스톤마다
보고서(이 폴더의 M2~M7.md)를 남겼고, 원래 여쭤봤어야 할 결정은 명세서 부록 "자율 진행 중 결정"(A1~A24)에 근거와 함께 모았습니다.
바꾸고 싶은 결정은 번호로 알려 주시면 됩니다.

## 직접 확인하실 것 (우선순위 순)

1. Actions의 최근 `windows` 실행 → Artifacts `evolab-windows` 내려받기 → 압축 풀고 `evolab.exe` 더블클릭
   (가능하면 파이썬이 없는 PC에서)
2. **실험실**: 달 착륙선 새로 시작 → 관전 모드로 집단이 내려오는 것, 배속, 멈춤 → 정지 조건 바꾸기 → 이어서
3. **실험실**: 트랙 자동차로 바꿔 학습 → 2~3분 안에 트랙을 도는지, 차를 클릭하면 레이와 뉴런 값
4. **에디터**: 내장 예제에서 시작 → 부품 끌기·되돌리기 → 다리 길이 '진화' 켜기 → 실험실로 보내기
5. **비교**: 반복 실행(시드 5개)으로 같은 설정을 돌리고 평균 선과 띠
6. **기록**: 실행 열기·이어하기·재현 묶음·CSV, 노트북 전원 연결 상태에서 `evolab-cli.exe bench` 수치

## 독립 검토

모든 코드를 다른 에이전트가 따로 읽고, 문제를 실제로 재현한 것만 고쳤습니다(고칠 때마다 회귀 테스트).

| 검토 | 확인된 문제 | 처리 |
| --- | --- | --- |
| 학습 엔진·저장(세션, 트레이너, 워커 풀, 실행 폴더, 재현 묶음, 학습 방법) | 7건 + 의심 2건 | 모두 고침 |
| 환경 런타임(차량, 레이, 체크포인트, 모터, 트랙·언덕) | 6건 | 모두 고침 |
| 화면(실험실, 에디터, 비교·기록, 주 창·배포, 화면 흐름의 결정성) | 25건(중복 합치면 약 21건) | 모두 고침. 고친 뒤 다른 에이전트가 원래 재현 스크립트로 다시 확인 |

화면 검토에서 고친 것 가운데 쓰실 때 느껴지는 것:

- 학습 중인 실행(실험실 또는 반복 실행)은 실험실 '이어서'와 기록 '이어하기'로 이어 가지 않습니다. 예전에는 두 곳이 같은 폴더에
  쓸 수 있었고, 거절된 이어하기가 빈 분기 폴더를 남겼습니다.
- 에디터는 다시 열 수 없는 파일을 저장하지 않습니다. 범위 밖 숫자는 칸에서 바로 막고, Enter 없이 저장해도 입력 중인 이름·참조가
  저장됩니다. 붙여넣기가 종류·태그 칸을 망가뜨리지 않고, 한글 부품 이름과 예약어(time 등)를 바르게 다룹니다.
- 설정에서 데이터 폴더를 바꾸면 직접 조종 기록도 따라가고, '내 최고 기록'은 .evoplay 기록과 예전 위치를 함께 봅니다.
- 명령줄 도구의 잘못된 숫자 인수는 한국어 문장과 종료 코드 2로 끝납니다(트레이스백 없음).
- 학습 중 환경·설정 변경이 디스크 쓰기에서 실패하면 기록과 학습 상태를 바꾸기 전으로 되돌립니다(이어하기·재현이 어긋나지 않음).

## 알려진 한계와 남은 위험

- **착륙선 시드 편차**: 고정 시드 1·2·3은 87~95%지만, 따로 잰 시드 가운데 시드 11은 15분에 17%, 시드 14는 시험 7만 회에 48%였고,
  M6 비교 실행의 시드 4·5도 시험 7만 회에 29%·37%였습니다. v1.1(정체 시 자동 재시작, 예선)에서 다룹니다.
  개체 수 64도, 초기 시그마 1.0(시드 1·11·14에서 21%·14%·16%)도 낫지 않았습니다(M2 보고서). 실험실에서 학습이 정체하면 시드를
  바꿔 다시 시작하는 것이 가장 빠릅니다.
- **측정 환경**: 모든 수치는 리눅스 4코어 클라우드 컨테이너에서 쟀습니다. 노트북(4코어, MX450)의 실제 수치는 `bench`로 확인이 필요합니다.
  입력 지연은 다른 학습과 함께 돈 부하 상태에서 쟀습니다.
- **2차로 둔 것**: 격자 세계, 분할 화면 경주, 2차 그래프(유전자 지도, 몸 수치 추이, 뇌 들여다보기 그림, 궤적 밀도, 행동 분포),
  몸 구조 진화, 글라이더, 점프 게임, 폰 뷰어, 강화학습·새로움 탐색, GPU 가속, MP4 영상.
