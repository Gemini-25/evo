# research/ — 실험용 코드 (배포본에 들어가지 않음)

여기 있는 것은 설계 결정을 내리기 전에 돌려 보는 원형(prototype) 실험 코드다. 프로그램(`src/evolab`)의 일부가 아니고,
설치 파일·휴대용 zip에 들어가지 않으며 테스트(`tests/`)가 모으지도 않는다.

- `sports_proto/<항목>/` — 스포츠 프리셋 묶음(6.3.0·6.4.0)의 종목 원형: 손으로 짠 작은 물리 세계에서 스스로 대전 학습이
  되는지 먼저 재 본다. 긴 실행은 `.github/workflows/measure.yml`(측정용 러너)로 돌린다.

원형에서 잰 값은 보고서에 「원형(scratch 세계)」이라고 따로 적고, 출시 기준의 판정에는 실제 런타임에서 잰 값만 쓴다.
